# Blood Bank Management System

Database project developed for CSE 384: Database Design Lab.

## Technologies
- Oracle SQL
- PL/SQL
- OneCompiler

## Features
- Relational database design
- Primary and foreign key constraints
- JOIN operations
- Set operations
- Aggregate functions
- Nested and correlated subqueries
- Views
- PL/SQL procedures
- PL/SQL functions
- Arrays and loops
- Exception handling
- Cursors

## Source Code
The complete implementation is available in:
`blood_bank_management_system.sql`
